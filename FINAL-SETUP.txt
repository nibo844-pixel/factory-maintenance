Η εφαρμογή χρειάζεται server για να δουλεύουν 
όλοι μαζί με τα ίδια δεδομένα.

══════════════════════════════════════════════════
ΕΠΙΛΟΓΗ A: Server στο εργοστάσιο (ΠΡΟΤΕΙΝΟΜΕΝΗ)
══════════════════════════════════════════════════

Χρειάζεσαι: 
• Έναν υπολογιστή που παραμένει ανοιχτός
• WiFi router (όλοι στο ίδιο δίκτυο)

ΒΗΜΑΤΑ:
1. Κατέβασε Node.js: https://nodejs.org → LTS
2. Αποσυμπίεσε το ZIP στο C:\FactoryApp\
3. Άνοιξε cmd → cd C:\FactoryApp → npm install
4. Τρέξ: node server.js
5. Βρες το IP: cmd → ipconfig → IPv4

Τα κινητά μπαίνουν στο: http://[IP]:3000

Αυτόματη εκκίνηση: διπλό κλικ στο install.bat

══════════════════════════════════════════════════
ΕΠΙΛΟΓΗ B: Cloud (Vercel/Render)
══════════════════════════════════════════════════

Χρειάζεσαι: λογαριασμό στο Render.com (δωρεάν)

1. Δημιούργησε λογαριασμό στο https://render.com
2. New Web Service → Connect GitHub
3. Άνεβασε τον κώδικα
4. Auto-deploy
