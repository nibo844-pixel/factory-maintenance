ΠΡΟΫΠΟΘΕΣΗ (μόνο μία φορά)
─────────────────────────────
1. Κατέβασε το Node.js: https://nodejs.org
2. Εγκατέστησε: Next → Next → Finish


ΕΓΚΑΤΑΣΤΑΣΗ (μόνο μία φορά)
─────────────────────────────
1. Αποσυμπίεσε αυτό το αρχείο σε οποιοδήποτε μέρος
   (π.χ. C:\FactoryApp\)
2. Διπλό κλικ στο "setup.bat"
3. Περίμενε να τελειώσει
4. Είσαι έτοιμος!


ΚΑΘΗΜΕΡΙΝΗ ΧΡΗΣΗ
──────────────────
• Διπλό κλικ στο "Factory Maintenance" στην επιφάνεια
  (ή διπλό κλικ στο "START.bat" στον φάκελο)
• Άνοιξε browser → localhost:3000
• Login: admin / admin123


ΚΙΝΗΤΑ (WiFi)
─────────────
1. Στο PC: ανοίγεις cmd → τύπωσε: ipconfig
2. Βρες "IPv4 Address" (π.χ. 192.168.1.50)
3. Στο κινητό browser: http://192.168.1.50:3000
4. Εισόγιος με admin / admin123
5. Menu → "Προσθήκη στην αρχική οθόνη" για app icon


ΡΟΛΟΙ ΧΡΗΣΤΩΝ
──────────────
admin     → ΟΛΑ (ανέβασμα, διαγραφή, χρήστες)
supervisor → Ανέβασμα, μηχανήματα, logs
technician → Βλέπει + προσθέτει εργασίες


ΤΙ ΚΑΝΕΙ Η ΕΦΑΡΜΟΓΗ
─────────────────────
🗺️  Χάρτης εργοστασίου με clickable markers
📋  Ιστορικό συντήρησης για κάθε μηχάνημα
📦  Αποθήκη ανταλλακτικών
📊  Dashboard με στατιστικά
👥  Διαχείριση χρηστών


ΤΕΧΝΙΚΗ ΥΠΟΣΤΗΡΙΞΗ
────────────────────
• Αν δεν ανοίγει: διπλό κλικ στο START.bat
• Αν δεν λειτουργεί: επανεκκίνησε το PC
• Τα δεδομένα είναι στο data/factory.db (ασφαλή)
• Αν θέλεις backup: αντέγραψε τον φάκελο data/
